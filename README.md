# Saluhackers · Contexto de marca

Este repositorio es la fuente de verdad de marca, voz y diseño. Notion es la fuente de verdad de negocio. Ningún dato de negocio entra aquí.

## Qué es

Contexto de referencia de Saluhackers, escuela de formación en IA para profesionales sanitarios. Lo consumen personas y agentes (Claude Code, Claude Design) para producir piezas coherentes con la marca: carruseles de LinkedIn, herramientas web y otros materiales.

## Por dónde empezar

El mapa definitivo de archivos, qué manda sobre qué, los comandos de validación, las convenciones y las reglas de gobierno están en un solo sitio: [`CLAUDE.md`](CLAUDE.md). Lo leen los agentes al arrancar y es la referencia también para personas. Este README no lo repite para que no diverjan.

- Sistema de diseño: [`DESIGN.md`](DESIGN.md) y [`marca/tokens.css`](marca/tokens.css).
- Voz: [`marca/voz.md`](marca/voz.md).
- Decisiones abiertas y cerradas: [`DECISIONES.md`](DECISIONES.md).
